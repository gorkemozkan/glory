- Performance: startup time, list rendering, Reanimated/worklets, JS thread profiling, Hermes
- The Expo ecosystem: EAS Build/Update, config plugins, dev client, SDK upgrades
- iOS and Android store policy, review rules, privacy and data-collection requirements
- TypeScript type-system depth, build and tooling performance
- Camera, image processing, on-device ML inference
- Mobile subscriptions and paywalls, RevenueCat/Adapty, conversion and analytics
- System design and backend fundamentals, to the extent they affect a mobile developer
